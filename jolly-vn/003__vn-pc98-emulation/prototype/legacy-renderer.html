DISK DRIVES — HOT SWAP vs REBOOT

HDD boot.hdi.json
Chapter 1 boot image. Fixed at boot.
FD1 (empty)
Chapter floppy slot. Hot-swappable.
FD2 (spare / fallback slot)
Reserved seam. Holds stub chapters offline.

Transition verdict (demonstrated below, written in README): hot swap works — the engine re-reads one NovelML file per chapter, so a fetched .fdi loads mid-session. Reboot-with-new-URL (?hdd=...&fd1=...&run=1) is kept as the fallback and as the shareable link form.
